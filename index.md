# 🍀 How to Play on Mint’s Minecraft Server

Welcome to **Mint’s Awesome Modpack**!  
Follow this guide to install the pack through CurseForge and join the server at **mintcraft.se**.

---

## ⚠️ Before You Begin
- You must **own Minecraft: Java Edition** for **PC or Mac**.  
  (This modpack will **not** work with Minecraft Bedrock, the version used on consoles, tablets, or phones.)  
- Make sure you can launch regular Minecraft Java Edition at least once before continuing.  
- You’ll need a **Microsoft account** that owns Minecraft Java — you’ll sign in during setup if you aren’t already.

---

## 🧩 Step 1: Get the Modpack
1. Open this link in your web browser:  
   👉 [**Mint’s Awesome Modpack on CurseForge**](https://github.com/dubiousnate/mints-awesome-server)
2. Click the **“Install via CurseForge App”** button.  
   - This will open the **CurseForge App** and start installing the pack automatically.  
3. If you don’t have the CurseForge App yet, it will prompt you to download it.  
   - Follow the instructions to install and then return to the link above to click **“Install via App”** again.

---

## ⚙️ Step 2: Launch the Modpack
1. Open the **CurseForge App**.  
2. Go to **My Modpacks** and find **Mint’s Awesome Modpack** (look for the 🍀 icon).  
3. Click **Play** — this launches the **official Minecraft Launcher**.  
4. In the Minecraft Launcher:
   - You may be asked to **sign in with your Microsoft account** — do that using the same account that owns Minecraft Java Edition.  
   - Once signed in, click the **Play** button again to start the game.
5. You’ll see a message saying:  
   > “You are about to play a Minecraft: Java Edition installation that has been modified.”  
   This is **normal** — it just means Fabric and your mods are active.  
   ✅ Click **Play** again to continue.
6. When Minecraft starts, the **Essential Mod** may ask if you want to update it.  
   - This is **normal and safe** — you can click **Yes** to update or **No** to skip; either choice is fine.

---

## 🏠 Step 3: Join the Server
1. From the Minecraft main menu, click **Multiplayer**.  
2. You’ll see a warning that says:  
   > “⚠️ Caution: Third-Party Online Play”  
   This is **fine and expected** — it just reminds you that this is a private server.  
   - ✅ Click **Proceed** to continue.  
   - (Optional) Check **“Do not show this screen again”** if you don’t want to see this each time.
3. Click **Add Server**.  
4. Enter:
   - **Server Name:** Mint’s Awesome Server  
   - **Server Address:** `mintcraft.se`  
   - **Server Resource Packs:** set this to **Enabled** instead of **Prompt**, so you’ll automatically get the server’s textures and the full experience.
5. Click **Done**, then select the server and click **Join Server**.

---

## 💡 Tips
- Use the latest version of **Mint’s Awesome Modpack**.  
- The server uses **AutoModpack** under the hood, which will automatically download or update mods as needed when you connect.  
  ⏳ *Your first connection may take a few minutes to finish setting everything up — that’s normal!*  
- If you get a “version mismatch” or “missing mod” warning, restart Minecraft — AutoModpack will fix it.  

---

## 🎮 You’re Ready to Play!
That’s it! You’re all set to explore, build, and have fun on **Mint’s Awesome Server** with friends and family.  
See you on **Mint’s Awesome Server!** 🍀
